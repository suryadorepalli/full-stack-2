# Suriya Calendar Studio

A clean React-based interactive scheduling calendar for the academic objective: time-based visualization, calendar scheduling, structured event mapping, click interactions, and drag-and-drop.

## Demo login
- Username: `suriya`
- Password: `suriya`

## Run
```bash
npm install
npm run dev
```

## Build / test
```bash
npm run build
npm run test
```

## Features
- Login screen
- Light / dark mode
- Month calendar with fully visible 7-column layout
- Click a date to create an event
- Drag an existing event to another day to reschedule it
- Drag the "Drag here, then drop on a day to create" handle onto a day to create an event
- Event view, edit and delete
- Search and category legend
- Upcoming events sidebar
- LocalStorage persistence; no backend required
- Responsive mobile/tablet/desktop layout
