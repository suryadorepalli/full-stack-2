# FSD2 Repository

This repository contains the RBAC Authentication Web Project built with React and Vite.

## Project Included

- RBAC Authentication Web Project
  - Role-based authentication flow
  - Protected routes
  - Demo login for Admin, Editor, and Viewer
  - Frontend routing and UI components

## Technologies Used

- React
- Vite
- React Router DOM
- Axios
- JavaScript
- CSS

## Getting Started

1. Open the project folder:
   ```bash
   cd RBAC_Authentication_Web_Project
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open the local URL shown by Vite in your browser.
